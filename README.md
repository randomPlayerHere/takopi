# Us 🐙

A cute and interactive web app celebrating togetherness with adorable octopuses!

## 🌸 What is this?

This is a simple, charming progressive web app (PWA) that brings a little joy to your day. Click on the octopus to create floating hearts and spread the love!

## ✨ Features

- 🐙 Cute octopus character interactions
- 💕 Animated floating hearts on click
- 🎨 Beautiful pink gradient background
- 📱 Works on mobile and desktop
- 🌐 Progressive Web App (installable!)
- 🚀 Fast and lightweight

## 🛠️ Tech Stack

- Pure HTML & CSS & JavaScript
- Firebase Hosting
- Web Manifest for PWA support
- Service Worker for offline functionality

## 🚀 Deployment

This project is deployed on Firebase Hosting and can be accessed at: https://takopi-s-mood.web.app

## 💻 Local Development

Simply open `index.html` in your browser to get started!

## 📦 Files

- `index.html` - Main app file
- `service-worker.js` - PWA service worker
- `manifest.json` - PWA manifest
- `firebase.json` - Firebase configuration
